# صوت المستقبل - منصة تعليم الإعلام للأطفال

منصة عربية تعلّم الأطفال مبادئ الصحافة والإعلام، بصفحات محتوى ونظام تعليقات ومشاركات على PHP وMySQL.

## 1 ما هو المشروع

عنوان الرئيسية: «صوت المستقبل - منصة تعليم الإعلام للأطفال». الفكرة في التوثيق السابق ما زالت في الصفحات: تعليم الصحافة بطريقة مبسطة، مع أقسام للتعريف والتدريب والألعاب والذاكرة والمشاركات. الواجهة Dark Mode ومتجاوبة كما وصف README السابق، والمحتوى في HTML ثابت بالإضافة إلى تعليقات ومشاركات من قاعدة البيانات.

## 2 لماذا بُني

النصوص تقدم المنصة كمكان يبني وعياً إعلامياً للأطفال: فهم دور الإعلام واستخدامه بشكل إيجابي، مع تدريب عملي وقصص ونشاطات. غير موثق جهة رسمية خارج نصوص الصفحات.

## 3 من يستخدمه

| الشخص | الاستخدام |
| --- | --- |
| طفل أو ولي أمر | يقرأ الأقسام ويعلّق |
| مشارك | يرسل عملاً من صفحة المشاركات مع ملف |
| مشرف | غير موجود في الملفات الحالية كلوحة دخول |

التعليقات التجريبية في `database.sql` بأسماء عربية ونصوص عن استفادة الأطفال.

## 4 الميزات

- رئيسية برسالة المنصة.
- صفحات: من نحن، كيف أكون إعلامي صغير، الألعاب والمسابقات، ذاكرة الإعلام، المشاركات والفعاليات، من قلمنا، الإخراج الصحفي.
- تعليقات حسب اسم الصفحة: جلب وإرسال.
- صفحة المشاركات تعرض كل التعليقات وتستقبل مشاركات (اسم، عنوان، وصف، نوع، ملف).
- إنشاء القاعدة والجداول عند تحميل `api/config.php` إذا استطاع MySQL ذلك.
- Favicon يشير إلى `assets/images/Logo.PNG`. الشعار المعروض في الصفحات `Logo2.PNG` و`Logo1.png`.
- خط IBM Plex Sans Arabic.

## 5 سير العمل

```
صفحة HTML
   |
   v
assets/js/main.js
   | GET get_comments.php?page=
   | POST submit_comment.php
   v
MySQL comments

pages/activities.html
   | get_all_comments.php
   | get_submissions.php
   | POST submit_submission.php (ملف)
   v
MySQL submissions + مجلد رفع يحدده السكربت
```

## 6 أمثلة حقيقية

بذور `database.sql` لتعليقات صفحات: `index`، `become-journalist`، `games`، `archive`، `about-us`، `activities`، `learning-space`. مثال: صفحة `index` واسم «محمد العتيبي» ونص عن استفادة طفل، بتاريخ مخزن `2025-11-01 10:30:00`.

المشاركة تخزن name وtitle وdescription وtype وfile_url وfile_name.

## 7 رحلة المستخدم

1. يفتح `index.html` عبر خادم PHP.
2. يتنقل بين الأقسام.
3. يقرأ تعليقات الصفحة ويرسل اسماً ونصاً.
4. في المشاركات يرى التعليقات من كل الصفحات ويرفع عملاً ثم يراه في القائمة إن نجح الحفظ.
5. التاريخ في الواجهة يمر عبر `formatDate` في `main.js`.

التعليقات لا تعمل عند فتح الملف مباشرة من القرص، كما ذكر README السابق، لأن الطلب يحتاج PHP.

## 18 الواجهة الأمامية

تنقل بين الأقسام، بطاقات، نماذج تعليق. `activities.html` يحمّل التعليقات والمشاركات دفعة ويعرض زر المزيد عبر دوال `loadMoreComments` و`loadMoreSubmissions`. الأيقونة المعلنة `Logo.PNG`. الصور المستخدمة فعلياً في الجسم تشمل `Logo1.png` و`Logo2.PNG`.

## 19 الخادم

`config.php` يعرّف:

| الثابت | القيمة في الملف |
| --- | --- |
| DB_HOST | localhost |
| DB_USER | root |
| DB_PASS | فارغة |
| DB_NAME | sawt_almustaqbal |

إذا فشل الاتصال يحاول إنشاء القاعدة بمستخدم بلا اسم قاعدة ثم يعيد الاتصال. `getDBConnection` يعيد `null` عند الفشل. أخطاء التهيئة التلقائية تُبتلع في `catch`.

## 20 تدفق الطلب

`main.js` يحسب مسار API بـ `getApiPath()` ثم:

- `GET get_comments.php?page={اسم}` والافتراضي في PHP هو `index` إن غاب المعامل.
- `POST submit_comment.php` بالحقول page وname وcomment.

المشاركات: `POST` متعدد الأجزاء إلى `submit_submission.php` بالحقول name وtitle وdescription وtype وملف `file`. `move_uploaded_file` ينقل الملف إلى المسار الذي يبنيه السكربت.

## 21 قاعدة البيانات

`database.sql` ينشئ القاعدة وجدول comments فقط، ثم يدرج البذور. جدول submissions يُنشأ من `initDatabase()` وليس من ملف SQL. لذلك استيراد SQL وحده لا ينشئ المشاركات حتى يُطلب PHP مرة.

## 24 الأمان

- الكتابة مفتوحة بلا رمز.
- مستخدم MySQL في الملف هو root وكلمة فارغة، ويحتاج صلاحية إنشاء قاعدة حتى يعمل المسار التلقائي.
- رفع المشاركات يعتمد على تحقق السكربت من الملف قبل `move_uploaded_file`. راجع الامتدادات داخل `submit_submission.php` قبل النشر.
- لا CSRF.
- رسائل فشل الاتصال للمستخدم عامة عند إعادة `null`، بينما إنشاء القاعدة يتم بصلاحيات عالية إن نجح الاتصال بلا اسم قاعدة.

## 25 الإعدادات

عدّل الثوابت الأربعة في `api/config.php` إذا اختلفت بيئة MySQL. لا `.env`.

## 28 الملفات والتخزين

صور `assets/images/` وفيديو `assets/Videos/`. مرفقات المشاركات تُخزَّن بالمسار الذي يكتبه `submit_submission.php` ويُحفظ الرابط في `file_url`. الخطوط مع `OFL.txt`.

## 29 السجلات

غير موجود مجلد log. فشل التهيئة لا يُعاد إلى الزائر من `config.php`.

## 30 التثبيت

1. شغّل Apache وMySQL.
2. انسخ المجلد إلى جذر الخادم، مثلاً `htdocs`.
3. راجع `api/config.php`.
4. افتح `http://localhost/Sawt Almustaqbal/index.html` (المسار يعتمد على اسم المجلد وفيه مسافة).
5. أول طلب يحمّل `config.php` ينشئ القاعدة والجدولين إذا كانت صلاحية المستخدم تسمح.
6. لاستيراد التعليقات الجاهزة نفّذ `database.sql`.

## 31 دليل المطور

- مفتاح `page` يجب أن يطابق ما ترسله الصفحة حتى تُفلتر التعليقات.
- أضف صفحة جديدة مع نفس نمط `main.js` ومعرّف الصفحة.
- لا تعتمد على README القديم لأسماء الملفات. القائمة الحالية في قسم الوحدات.
- أيقونة `Logo.PNG` غير ظاهرة في قائمة الملفات الحالية، بينما `Logo1.png` و`Logo2.PNG` موجودان.

## 32 النشر

خادم PHP وMySQL مع HTTPS. أنشئ مستخدماً بصلاحية محدودة على قاعدة جاهزة بدل root الذي ينشئ قواعد. عطّل إنشاء القاعدة التلقائي إذا كان حساب الإنتاج لا يملك هذه الصلاحية، بعد إنشاء الجداول مرة واحدة. غير موثق نطاق إنتاج.

## 33 النسخ الاحتياطي

## 37 الحالة الحالية

الصفحات السبع الفرعية والرئيسية وواجهات التعليق والمشاركة موجودة. التناقضات مع README السابق ومع SQL:

| المصدر | الواقع في الملفات |
| --- | --- |
| README يذكر `learning-space.html` ضمن `pages/` | الملف غير موجود |
| README لا يذكر `our-articles.html` ولا `editorial-design.html` ولا واجهات المشاركات | الملفات وPHP موجودة |
| README يقول إن الجدول يُنشأ عند أول طلب تعليقات ويذكر جدول التعليقات فقط | `initDatabase` ينشئ comments وsubmissions |
| بذور `learning-space` | لا HTML بهذا الاسم |
| favicon `Logo.PNG` | غير موجود في قائمة الصور الحالية |

بقي صحيحاً: الفكرة التعليمية، PHP وMySQLi، اسم القاعدة `sawt_almustaqbal`، إعداد root المحلي الفارغ، وأسماء صفحات من نحن والألعاب والذاكرة والإعلامي الصغير والمشاركات.

## For Non-Technical Users

الموقع للأطفال والعائلات للتعرّف على الإعلام والصحافة باللعب والقصص والخطوات العملية. يمكن كتابة تعليق على الصفحة. في قسم المشاركات يمكن إرسال عمل مع ملف. هذا يعمل عندما يكون الموقع مفتوحاً من خادم المدرسة أو الجهاز لا من ملف تم النقر عليه فقط.

## For Developers

طابق مفتاح `page` بين HTML وPHP. أضف `Logo.PNG` أو عدّل وسم الأيقونة إلى ملف موجود. لا تعطِ مستخدم الإنتاج صلاحية إنشاء قواعد. راجع التحقق من نوع ملف المشاركة قبل أي نشر عام.
